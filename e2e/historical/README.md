# Historical browser specifications

These 15 original files preserve 22 scenarios for the retired pre-Canonical client. They are retained as historical evidence and remain typechecked; they are deliberately outside current Playwright discovery. This is an explicit product-scope migration, not a legacy test pass or a skipped current regression.

See [scenario disposition and current evidence](../../docs/faro/BROWSER_ACCEPTANCE_SCOPE.md). Current public consent, axe, reflow, privacy and real Canonical journeys execute through the default browser command. Do not restore CV/EHV or mock retired endpoints to make these historical expectations pass.
