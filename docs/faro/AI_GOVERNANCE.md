# AI governance

There is no activated external recruitment AI provider in the Canonical runtime. New experience suggestions use `local-question-rules-v3` with `faro-skill-proposal-ids-v1` schema provenance and are labelled as local rules in the workspace. Complete normalized alias boundaries avoid administrative prose proposing ADR and PostScript proposing TypeScript. Historical v1/v2 proposals retain their stored version and are not regenerated. Suggestions are persisted PENDING; only explicit candidate confirmation creates a DECLARED skill claim. Confirmation is not independent verification. Rationale is authored catalog text, never a copy of private activity/instructions; client-supplied provenance or verification cannot replace server-produced values. Unknown historical producer/prompt/confidence remains unknown.

Assessment creation accepts AI origin only as provenance. A submitted approval flag cannot make a definition published or assignable: create always stores DRAFT, review and conscious human approval precede assignment. Objective quiz scoring uses deterministic answer rules. The system does not auto-hire, auto-reject or produce a global candidate/potential score.

Shared AI gateway now enforces minimized bounded input, whole-response deadline, byte/token ceilings, redirect refusal, output schema/semantic validation, model/prompt/schema/input-hash provenance and controlled errors without private raw content. Both SQLite and native PostgreSQL reserve the global UTC-day request budget atomically before egress; failed/in-flight calls consume slots across reconstruction/competing connections. Audit admission failure refuses before egress. Actual tests use synthetic loopback providers only. Provider terms/protected credentials/approved spending and genuine human review still gate live use. Gateway has no publication/decision capability; local confirmation/manual fallback remains authoritative. Free-text inputs and model output are untrusted data.

LEGAL BLOCKER for production recruitment AI/scoring until qualification, GDPR profiling/automated-decision assessment, DPIA and genuine human review are resolved. Source/legal review remains external evidence; this document does not claim legal clearance.
