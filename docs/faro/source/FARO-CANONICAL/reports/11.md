# UPDATED RECRUITMENT STATE MACHINE

FARO CANONICAL · 2026-09-16 · Polska · TARGET, nie deklaracja wdrożenia

## Osobne automaty, jedna oś czasu

InterestStatus (relacja), CurrentStage, AssessmentAttempt, Interview i ModerationCase nie są jednym enumem. Dzięki temu można mieć ukończony assessment i przełożoną rozmowę bez sprzecznego statusu. Oś czasu łączy zdarzenia, ale nie zastępuje encji.

| Zdarzenie / stan | Aktor i warunek | Widok kandydata / firmy | Zegar i powiadomienie | Wpływ na rzetelność |
|---|---|---|---|---|
| INTERESTED / AWAITING_EMPLOYER | Kandydat zatwierdza projekcję i ofertęVersion | Wysłano / nowe zainteresowanie | Uruchom responseDueAt; receipt | Samo zgłoszenie nie daje reputacji |
| CLARIFICATION_REQUESTED | Rekruter pyta o istotną brakującą informację | Konkretne pytanie / oczekiwanie | Odpowiedź merytoryczna; osobny termin odpowiedzi | Nie liczyć pustej wiadomości jako postęp |
| ACCEPTED_TO_NEXT_STAGE | Uprawniony rekruter, aktywny proces | Następny etap / lista aktywnych | Zamknij first response clock;powiadomienie następnego kroku | Nie ujawnia automatycznie telefonu |
| ASSESSMENT_REQUESTED | Approved version i jawne parametry | Zaproszenie / oczekuje | Deadline wykonania; neutralne przypomnienie | Nie jest zatrudnieniem ani NSM sukcesem |
| ASSESSMENT_STARTED | Kandydat jawnie Start | Timer / rozpoczęto | Server timer | Brak automatycznej oceny rzetelności |
| ASSESSMENT_COMPLETED | Submit lub zgodne zamknięcie próby | Oczekuje oceny / do oceny | Review due;powiadomienie | Wynik nie wpływa na reputację |
| INTERVIEW_PROPOSED | Dostępny slot, rekruter lub uzgodniona propozycja | Wybierz/potwierdź / oczekuje | Termin potwierdzenia | Niepotwierdzony slot nie może być no-show |
| INTERVIEW_CONFIRMED | Akceptacja obu stron i atomowa rezerwacja | Kiedy/gdzie / kalendarz | Reminder, cancel/reschedule | Dopiero potwierdzenie tworzy zobowiązanie |
| INTERVIEW_COMPLETED | Potwierdzone zdarzenie / rozbieżność do wyjaśnienia | Decyzja do daty / do decyzji | DecisionDueAt | Postęp, nie gwarancja oferty |
| OFFERED | Firma przekazuje warunki | Oferta pracy / czeka na decyzję | Jawny termin, bez fake countdown | Brak kary za odmowę |
| HIRED | Potwierdzenie wyniku, oznaczenie źródła | Zakończono / zatrudniono | Wyłącz zbędne przypomnienia | Sam claim firmy nie jest niezależnie potwierdzonym sukcesem |
| REJECTED | Firma + structured reason | Powód i wymaganie / zamknięte | Zamknięcie + powiadomienie | Nie pogarsza wiarygodności osoby |
| WITHDRAWN | Kandydat | Wycofano / zakończone | Wyłącz zadania i sloty | Brak kary za zmianę zdania |
| CANCELLED | Firma zamyka potrzebę lub moderacja | Przyczyna / zamknięte | Informacja do wszystkich aktywnych | Oddzielnie od braku kompetencji |
| NO_SHOW_CASE | Zgłoszenie strony po potwierdzonym spotkaniu | Wyjaśnij / sprawa | Grace period i appeal | Nie jest natychmiastowym negatywnym faktem |

Termin grace period, liczba przypomnień i reconfirmation to parametry polityki TEST FIRST, nie udowodnione przez badania wartości. Nie implementować domyślnie progów2+2tygodnie i mnożników50/25. Czasy przechowujemy UTC, prezentujemy Europe/Warsaw lub wybraną IANA; testy zmiany czasu obowiązkowe.

## Integralność

Każda komenda: actor, organization/process scope, expectedVersion, idempotencyKey, reason tam gdzie wymagany. Transakcja zapisuje stan, audit event i outbox. Konflikt równoległy withdraw/reject nie nadpisuje wycofania bez śladu; terminalne stany nie są samowolnie wskrzeszane. Ponowne zainteresowanie to świadoma nowa relacja z linkiem historii, nie reset danych trust.

Odpowiedź merytoryczna i postęp to różne zdarzenia. „Dziękujemy” nie kończy zegara odpowiedzi. Odrzucenie kończy oczekiwanie, ale nie liczy się jako pozytywny postęp. Prośba o to samo potwierdzenie co tydzień nie może mechanicznie podbijać NSM.

Kalendarz: dostępność, nie pełna treść prywatnego kalendarza. MVP ręczne sloty/ICS/meeting link; integracje Google/Microsoft później, minimalne scopes. Prywatny tytuł zdarzenia nie trafia do organizacji. No-show przy problemie platformy lub błędnym przypomnieniu wymaga wyjaśnienia, nie automatycznej sankcji.
