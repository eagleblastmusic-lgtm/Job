# FARO PRODUCT CONSTITUTION

FARO CANONICAL · 2026-09-16 · Polska · TARGET, nie deklaracja wdrożenia

## Misja i granice

Faro łączy ludzi z pracą na podstawie realnych czynności, kompetencji, możliwości nauki, warunków i rzetelnego procesu. Nie ocenia życiorysu ani wartości człowieka. Ambicja zmiany rekrutacji pozostaje misją, nie udowodnioną skutecznością produktu.

| Zasada | Wymóg produktu | Test naruszenia |
|---|---|---|
| NO CV | Żadnego dokumentu CV w employer-facing rekrutacji | Firma nie może wymagać, otrzymać ani pobrać CV przez dozwolony flow |
| NO PHOTO / AGE / SURNAME FIRST STAGE | Pierwsza projekcja bez tych danych, z imieniem | API, eksport, powiadomienie i log nie omijają projekcji |
| NO EMPLOYER PRESTIGE SIGNAL | Nigdy nazw poprzednich firm i stanowisk w profilu dla firmy | Dowody i metadane też nie przemycają tych etykiet |
| SKILLS OVER TITLES | Czynności i konkretne umiejętności | Zawód nie implikuje potwierdzonego skill |
| LEARNING MATTERS | Aspiracje i WILL_TEACH są pełnoprawną informacją | Brak umiejętności, której firma nauczy, nie jest blokadą |
| TRANSPARENCY | Płaca, warunki, etapy, dwa zegary, diff | Zmiana nie nadpisuje snapshotu zgłoszenia |
| REASON FOR REJECTION | Konkretny reason i requirement tam, gdzie dotyczy | Generyczne „lepszy kandydat” nie przechodzi walidacji |
| SYMMETRIC ACCOUNTABILITY | Obie strony mogą anulować, wyjaśnić i odwołać się | Kandydat nie jest karany za odmowę oferty, brak skill lub przerwę |
| NO PAY-TO-WIN | Płatność nie wpływa na ranking ani dostęp do lepszych osób | Wynik identyczny przy zmianie wyłącznie billing plan |
| EXPLAINABILITY | Fakty, deklaracje, brak danych i wnioski oddzielnie | Unknown nie staje się automatycznie zerem |
| USER CONTROL | Podgląd projekcji, prywatne obserwowanie, grant wyniku/telefonu | Akceptacja firmy nie ujawnia telefonu bez kontroli osoby |
| NATIONWIDE | Publiczny produkt dostępny w całej Polsce | Brak geofence, whitelist miast i regionalnego warunku rejestracji |
| FREE-FIRST | Na start obie strony korzystają bezpłatnie | Brak checkout i komunikatu Free Plan w launchu |

## Normy operacyjne

Prawo i bezpieczeństwo mogą wstrzymać uruchomienie funkcji, ale nie zmieniają po cichu wizji. W razie konfliktu zapisujemy **FOUNDER DECISION → EVIDENCE CONFLICT → RECOMMENDED REVIEW**, właściciela i bezpieczną ścieżkę. Prawdziwa dostępność nie jest negocjowalna jako eksperyment konwersji. Nie przyjmujemy specjalnego modułu accommodations do core, lecz nie uchylamy wymaganych prawem dostosowań.

Odrzucone funkcje nie wracają przez zmianę nazwy. „Wartość godziny życia” byłaby tym samym co odrzucone Effective Hourly Value. „Ocena potencjału” byłaby zakazanym person score. Publiczny rating firmy nie staje się dopuszczalny przez nazwanie go feedbackiem.

Marka: umbrella **Faro. Twój nawigator na rynku pracy.** Obietnica produktu: **Faro. Wiesz, co dalej.** Starsze „I wiesz, co dalej” jest zastąpione w aktualnym copy. To aktualizacja języka, nie polecenie przerysowania logo.
