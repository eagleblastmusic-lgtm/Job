# UPDATED NATIVE OFFER SPECIFICATION

FARO CANONICAL · 2026-09-16 · Polska · TARGET, nie deklaracja wdrożenia

## Model i publikacja

Offer = identity organizacji + niezmienne OfferVersion. Native i ExternalOpportunity są różnymi typami. Native przechodzi DRAFT → IN_REVIEW → PUBLISHED → PAUSED/CLOSED; REJECTED_BY_MODERATION i REMOVED mają osobną historię sprawy. Repost nie tworzy czystej historii wiarygodności.

| Blok | Pola wymagane / zasady |
|---|---|
| Praca | Tytuł aktualnej oferty, rzeczywiste zadania, liczba wakatów jeśli znana, odpowiedzialny rekruter |
| Kompetencje | MUST/NICE/WILL_TEACH, poziom zadaniowy, uzasadnienie wymogów, formalne uprawnienia |
| Nauka | Czego nauczymy, forma wsparcia i odpowiedzialność; nie automatyczny benefit AI |
| Płaca | Minimum/maximum, waluta, podstawa, okres, typ umowy, gwarantowane/zmienne, FTE/godziny |
| Czas | Godziny/zakres, zmiany, nocne, weekendy i ich częstość; unknown widoczne |
| Miejsce | Lokalizacja lub obszar, remote/hybrid/on-site, liczba dni onsite/remote i okres odniesienia |
| Proces | Pierwsza odpowiedź, etapy, liczba rozmów, assessment i jego czas, decyzja po rozmowie |
| Aktualność | PublishedAt, confirmedActiveAt, closesAt, versionId, polityka reconfirmation |

Model salary nie ma jednego pola bruttoNettoB2B: B2B to typ kontraktu, nie podstawa podatkowa. `contractType`, `amountBasis=GROSS_EMPLOYMENT|GROSS_CIVIL|NET_EMPLOYMENT_DECLARED|B2B_NET_INVOICE_EXCL_VAT`, `period=HOUR|DAY|MONTH|YEAR`, `currency`, `guaranteedMin`, `guaranteedMax`, `variableDescription`, `fte`, `hoursPerPeriod`. Zmienne wynagrodzenie osobno; nie reklamować maksymalnej prowizji jako gwarantowanego minimum. Kilka kontraktów to kilka salary options, nie mieszana para widełek. Netto deklarowane przez firmę nie zastępuje prywatnego szacunku dla konkretnej osoby.

Publikacja blokowana, jeśli nie ma salary option, minimum>maximum, nieznana podstawa, brak przypisanego odpowiedzialnego albo niezatwierdzone AI changes. Stawka „od0” i absurdalnie szeroki przedział wymagają review jakości, nie automatycznego twierdzenia o złamaniu prawa. Zgodność z minimalnymi stawkami zależy od rodzaju umowy i daty, do sprawdzenia aktualnym modułem prawa.

Faro wymaga płacy w ogłoszeniu jako własnej reguły. Ustawa nie uzasadnia uproszczenia „każde polskie ogłoszenie musi mieć widełki”: przewiduje różne momenty przekazania informacji zależnie od przebiegu rekrutacji. [S02 — Dz.U.2025 poz.807](https://eli.gov.pl/api/acts/DU/2025/807/text/T/D20250807L.pdf), sprawdzono 16.09.2026.

## Zmiany, zegary i obserwowanie

Interest zapisuje OfferVersionId. Diff porównuje tę wersję z bieżącą: salary option, work mode, miejsce, wymagania, czas, etapy, assessment, terminy. Pokazuje poprzednia→nowa wartość z datą i autorem. Nie kwalifikuje każdej zmiany jako pogorszenia. Wycofanie jest łatwe i bez kary. Istotne zmiany nie mogą wymagać milczącej akceptacji.

Dwa zegary: responseDueAt obliczony przy zgłoszeniu według zadeklarowanej polityki (jawne dni kalendarzowe/robocze i strefa); stageDueAt/decisionDueAt według etapu. Autoack nie zamyka response clock. Nowy deadline nie usuwa starego przekroczenia. Niedostarczony e-mail nie jest dowodem ghostingu kandydata.

Watch jest prywatnym zasobem candidateId×offerId z ustawieniami alertów. Pracodawca nie dostaje listy obserwujących ani możliwości kontaktu; także eksport i B2Banalytics nie ujawniają tożsamości. Zamknięcie kończy nowe zainteresowania, ale zachowuje legalnie potrzebną historię i komunikuje los istniejących procesów. Pauza nie udaje zamknięcia.

### Doprecyzowanie kwot i podstawy

Kwoty pieniężne przechowujemy w najmniejszych jednostkach waluty (integer/decimal), nie w binarnych float. Dla umów cywilnoprawnych istnieje odrębna podstawa GROSS_CIVIL. Deklarowane netto firmy nie może być jedynym substytutem wymaganej jawnej podstawy brutto lub B2B bez VAT; pozostaje dodatkową deklaracją, nie indywidualnym wynikiem kalkulatora.
